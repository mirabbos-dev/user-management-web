# User Management Web

React admin panel for the [user-management-api](https://github.com/mirabbos-dev/user-management-api). Built as a technical assignment.

**Stack:** React 18 · React Router · React Bootstrap · Axios

![Screenshot](docs/screenshot.png)

## Features
- Registration and login with JWT
- User table with selection
- Block, unblock and delete selected users

## Run locally
```bash
npm install
cp .env.example .env   # set REACT_APP_API_URL
npm start
```
